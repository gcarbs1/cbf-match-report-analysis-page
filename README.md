# CBF Match Report Analysis — Page

Static site published via GitHub Pages. This repo holds only the built output
(`index.html` + `fonts/`) — the data collection, cleaning, and tagging logic
live in the private repo [`cbf-match-report-analysis`](https://github.com/gcarbs1/cbf-match-report-analysis).

To publish an update, copy the latest `index.html` from the source repo into
this folder and push.
